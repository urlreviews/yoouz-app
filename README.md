# Yoouz PWA - Local Video Reviews & Business Discovery

Yoouz is a high-performance Progressive Web App (PWA) built for authentic local video reviews, place discovery, and community engagement.

## Features
- **Video Reviews**: Record 60-second authentic front-camera video reviews for local places.
- **bunny.net / Cloud SQL Backend**: Secure and scalable backend storage for users, places, and reviews.
- **Admin Dashboard**: Comprehensive analytics, user management, and place moderation.
- **Mobile-First Dark Mode**: Immersive mobile experience optimized for modern devices.

## Tech Stack
- React 18 + TypeScript + Vite
- Tailwind CSS
- Express / Node.js Backend
- Cloud SQL / PostgreSQL (via bunny.net integration)
