How to Add the Signature Image in Microsoft Outlook

  1. Click Download PNG (for Outlook) above or use the direct download link.
  2. Open Microsoft Outlook:
    • In Outlook Web / Mac / New Outlook: Click the Settings (Gear Icon) in the top right → Mail → Signatures.
    • In Classic Outlook Desktop: Go to File → Options → Mail → Signatures.
  3. In the signature editor box, click the Insert Picture / Image icon and choose the downloaded image from your desktop.
  4. Select the image in Outlook, click the Hyperlink icon, and enter: https://yoouz.com
  5. Click Save.
